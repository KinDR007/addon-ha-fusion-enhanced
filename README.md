# ha-fusion Enhanced - Home Assistant Add-on Repository

![Project Stage][project-stage-shield]
[![License][license-shield]](LICENSE)

Home Assistant add-on repository for **ha-fusion Enhanced** - a modern dashboard with advanced button layouts.

## About

This repository contains the Home Assistant add-on for ha-fusion Enhanced, which adds:

- ✨ Multiple button layout options (Rectangle, Square, Small Square, Icon-only)
- ✨ Multiline text support
- ✨ Flexible separator sizing
- ✨ Enhanced grid system for better space utilization

## Installation

Add this repository to your Home Assistant instance:

[![Add Repository](https://my.home-assistant.io/badges/supervisor_add_addon_repository.svg)](https://my.home-assistant.io/redirect/supervisor_add_addon_repository/?repository_url=https%3A%2F%2Fgithub.com%2FKinDR007%2Faddon-ha-fusion-enhanced)

Or manually:

1. Go to **Settings** → **Add-ons** → **Add-on Store**
2. Click **⋮** (menu) → **Repositories**
3. Add: `https://github.com/KinDR007/addon-ha-fusion-enhanced`
4. Click **Add**
